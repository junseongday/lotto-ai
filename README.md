# 🤖 LotterAI: AI 기반 로또 번호 추천기

**LotterAI**는 과거 로또 당첨 번호 데이터를 학습하여 다음 회차의 로또 번호를 예측하고 추천하는 딥러닝 프로젝트입니다. TensorFlow (Keras)를 사용하여 구현되었습니다.

## 🌟 주요 기능

- **데이터 기반 예측**: `lotto.csv` 파일의 과거 당첨 번호 데이터를 기반으로 패턴을 학습합니다.
- **딥러닝 모델**: 순차적 데이터 예측에 강점을 보이는 LSTM(Long Short-Term Memory) 모델을 사용합니다.
- **번호 추천**: 학습된 모델을 통해 다음 회차의 추천 번호 6개를 생성합니다.

## 📋 요구 사항

프로젝트 실행에 필요한 라이브러리는 다음과 같습니다.

- `tensorflow`
- `pandas`
- `numpy`
- `scikit-learn`

전체 목록은 `requirements.txt` 파일에서 확인할 수 있습니다.

## 🚀 설치 및 실행

1.  **프로젝트 클론**
    ```bash
    git clone https://github.com/your-username/lotterAI.git
    cd lotterAI
    ```

2.  **가상 환경 생성 및 활성화**
    ```bash
    python -m venv .venv
    source .venv/bin/activate
    ```

3.  **필요 라이브러리 설치**
    ```bash
    pip install -r requirements.txt
    ```

4.  **프로그램 실행**
    ```bash
    python main.py
    ```
    실행하면 학습 과정이 출력된 후, 추천 로또 번호가 화면에 표시됩니다.

## 📊 데이터

- `lotto.csv`: 모델 학습에 사용되는 로또 당첨 번호 데이터 파일입니다. 각 행은 하나의 회차를 의미하며, 6개의 당첨 번호와 보너스 번호로 구성되어 있습니다.
